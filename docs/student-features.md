# Функції застосунку для студентів і викладачів (довідник можливостей)

Цей документ містить актуальний перелік користувацьких функцій веб-застосунку **Розклад занять ДФКР**, синхронізований із поточною кодовою базою (`frontend/app/`, `frontend/components/`, `frontend/lib/`).

---

## 1. Основні можливості інтерфейсу

| Функція | Як працює в інтерфейсі | Ключові файли | Примітки |
|---|---|---|---|
| **Перший вхід та швидкий онбординг** | При першому відкритті (`WelcomeScreen.tsx`) користувач обирає роль («Студент» або «Викладач») та свою групу/ПІБ, після чого проходить лаконічний 15-секундний майстер (`StudentOnboardingModal.tsx` або `TeacherOnboardingModal.tsx`): вибір підгрупи з прев'ю викладачів (або введення PIN-коду викладача), теми оформлення та прив'язка Classroom. | `WelcomeScreen.tsx`, `StudentOnboardingModal.tsx`, `TeacherOnboardingModal.tsx` | Зберігає `schedule:setupComplete = "1"` у `localStorage`. |
| **Візуальний інтерактивний Гід (6 Stories)** | Кнопка `💡` у верхній шапці або пункт «Інтерактивний гід по застосунку» в `/settings` відкриває візуальний гід у форматі 6 Stories із перемикачем `[🎓 Студент \| 👨‍🏫 Викладач]` та живими інтерактивними демо-віджетами. | `GuideHubModal.tsx`, `SchedulePageClient.tsx` | Адаптується під пристрій: на ПК показує тижневу сітку й навігацію клавішами `←` / `→`, на смартфонах — ізольований тест свайпу картки пари. |
| **Швидкий вибір групи та викладача (Останні вибори)** | У модальному вікні вибору контексту та на сторінці `/statistics` відображаються чіпи до 3 останніх обраних груп або викладачів без порожніх слотів. Під час введення тексту в поле пошуку чіпи автоматично ховаються. | `RecentSelectionsChips.tsx`, `useRecentSelections.ts`, `SchedulePageClient.tsx` | Також підтримується миттєвий перехід на розклад викладача кліком по його ПІБ у картці пари з кнопкою швидкого повернення до своєї групи. |
| **Навігація за днями та тижнями** | На смартфонах — інтерактивний свайп-пейджер `DayPager` та смужка днів `MobileWeekDaysStrip`. На ПК — вигляд «День» або тижнева сітка Пн–Пт (`ScheduleWeekGrid`) із перемиканням клавішами `←` та `→`. | `DayPager.tsx`, `MobileWeekDaysStrip.tsx`, `ScheduleWeekGrid.tsx`, `DatePickerModal.tsx` | Бейдж у шапці показує номер тижня, `Чисельник` / `Знаменник` та поточний формат навчання курсу (`Очно` / `Дистанційно`). |
| **Жива пара та скорочені дні (50 хв)** | Під час поточної пари (за часом `Europe/Kyiv`) на картці відображається індикатор `● ще N хв` та заокруглена прогрес-лінія внизу картки. Для скорочених днів показується бейдж `⏱ 50 хв` із перерахованим часом дзвінків. | `LessonCard.tsx`, `ScheduleDay.tsx`, `ScheduleWeekGrid.tsx`, `app/bells/page.tsx` | Детальний розклад дзвінків також доступний на окремій сторінці `/bells`. |
| **Підгрупи (`1` / `2` / `Обидві`)** | Миттєве перемикання підгрупи кліком по бейджу `1 підгр.` / `2 підгр.` на картці пари або в `/settings`. У режимі `Обидві` розділені пари показують обох викладачів із індивідуальними кабінетами або онлайн-кнопками. | `LessonCard.tsx`, `useUserSettings.ts` | При активній онлайн-парі номер аудиторії приховується для збереження чистоти картки. |
| **Онлайн-пари та захист посилань** | Кнопки `Meet ↗`, `Zoom ↗`, `Онлайн ↗`. Для неавторизованих гостей посилання захищені (`🔒 Meet` / `🔒 Zoom`). Студенти відкривають посилання своєї групи через прив'язку Google Classroom, а викладачі — через PIN-код викладача. | `LessonCard.tsx`, `TeacherPinModal.tsx`, `useTeacherAccess.ts` | Надійно захищає онлайн-заняття коледжу від сторонніх осіб. |
| **Домашні завдання на картках розкладу** | На картках пар відображаються **лише активні нездані завдання** з дедлайном. Коли всі завдання з предмета виконано, блок ДЗ на картці пари повністю приховується (без зайвих плашок «Усе здано»). | `LessonCard.tsx`, `useClassroomSubmissions.ts` | Для пар із двома викладачами завдання кожного викладача групуються окремо. |
| **Екран «Завдання» (`MobileTasksView`)** | Доступний через нижню панель навігації на смартфоні або бічну панель на ПК. Містить перемикач тижня `‹ ... ›`, сегмент `[Цей тиждень \| Усі]`, розгорнуті фільтри за предметом і статусом та секцію боргів «З минулих тижнів». | `MobileTasksView.tsx`, `TaskCardItem.tsx`, `TaskFilters.tsx`, `useTaskGroups.ts` | Нездані завдання з минулих тижнів зберігаються у списку до моменту фактичної здачі (`TURNED_IN` / `RETURNED`). |
| **Вкладка «Оцінки» (`GradesView`) та авто-шкала** | Відображає середній бал (за 5-бальною та 12-бальною системами), розподіл оцінок `«5» / «4» / «3» / «2»`, пошук предмета та деталізацію робіт. Система автоматично визначає реальну шкалу предмета (`5`, `12` або `100` балів), навіть якщо в Classroom залишено стандартні 100 балів. | `GradesView.tsx`, `useGradesSummary.ts` | Працює повністю прозоро без спотворення середнього балу та без зайвих сервісних банерів. |
| **Шеринг розкладу (картинка або текст)** | Генерація темної PNG-картинки розкладу дня або тижня (`Canvas`) чи копіювання відформатованого тексту в буфер обміну. | `shareImage.ts`, `ScheduleDay.tsx`, `DayPager.tsx` | Підтримує Web Share API на мобільних пристроях. |
| **Статистика (`/statistics`) та Освітній процес (`/educational-process`)** | Сторінка `/statistics` показує прогрес вичитаних годин та пар за семестр для груп і викладачів. Сторінка `/educational-process` відображає графік семестрів, сесій, практик і канікул за курсами (1–4). | `app/statistics/page.tsx`, `app/educational-process/page.tsx` | Доступні з меню швидких дій у шапці та зі сторінки `/settings`. |
| **Індивідуальні SEO-сторінки груп та викладачів** | Прямі SSR-маршрути `/group/[code]` для кожної групи, `/teacher/[slug]` для кожного викладача та `/bells` для розкладу дзвінків зі структурованими даними Schema.org. | `app/group/[code]/page.tsx`, `app/teacher/[slug]/page.tsx`, `app/bells/page.tsx`, `app/sitemap.ts` | При переході за прямим посиланням клієнтський розклад одразу відкривається на відповідній групі чи викладачеві. |
