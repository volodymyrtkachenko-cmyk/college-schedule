## 2. Не для студентів (навмисно виключено з інструкції)

Наступні функції присутні в коді репозиторію, але призначені виключно для адміністраторів, редакторів розкладу або викладачів, тому в студентську інструкцію не включені:

1. **Панель керування розкладом (`/admin`) та сторінка входу (`/login`)**:
   - У `frontend/app/settings/page.tsx:585-626` секція `"Адміністрування"` (`"Увійти до панелі керування"` / `"Панель керування розкладом"`) призначена для авторизованих користувачів із ролями `admin` або `editor` (`canAccessAdmin`).
   - Адмін-панель (`frontend/app/admin/page.tsx`, `frontend/components/admin/*`) включає генератор розкладу, чернетки, імпорт, довідники, налаштування семестру та винятків режиму навчання.
2. **Редагування, перенесення, заміна та скасування пар (`canEdit`)**:
   - Кнопки `"Редагувати"`, меню `"⋯"` (`"Копіювати"`, `"Перемістити"`, `"Перенести"`, `"Поміняти місцями"`, `"Скасувати"`, `"Прибрати заміну"`, `"Відновити"`, `"Очистити слот"`, `"Змінити в постійному розкладі"`) у `frontend/components/LessonCard.tsx:1234-1431` та `frontend/components/ScheduleEditGrid.tsx` рендеряться лише тоді, коли передано прапорець `canEdit={true}` (який на головній сторінці студента завжди `false`).
3. **Редагування та історія приміток до пари (`LessonNoteModal`)**:
   - Пункти меню `"+ Примітка"` / `"Редагувати примітку"` та `"Історія примітки"` (`frontend/components/LessonCard.tsx:1398-1425`, `frontend/components/LessonNote.tsx`) доступні лише редакторам (`canEdit`). Студенти бачать лише готову текстову примітку внизу картки пари.
4. **Режим викладача та PIN-код викладача (`TeacherPinModal`, секція «Доступ викладача»)**:
   - Секція `"Доступ викладача"` у `frontend/app/settings/page.tsx:459-548` та модальне вікно `"Вхід для викладача"` (`frontend/components/TeacherPinModal.tsx`) показуються лише коли обрано роль `"Викладач"` (`scheduleMode === "teacher"`). В інструкції для студентів згадано лише підказку з цього вікна на випадок, якщо студент перейшов у розклад викладача і натиснув на закрите посилання чужої групи.
5. **Невикористані в поточному UI компоненти та функції**:
   - Компоненти `frontend/components/EventsTimeline.tsx` та `frontend/components/InsightBar.tsx` існують у папці `components/`, але ніде не імпортуються і не рендеряться на сторінках застосунку.
   - Функція `handleDownloadOffline` у `frontend/app/page.tsx:105-118` оголошена, але не прив'язана до жодної кнопки в JSX (офлайн-кешування відбувається автоматично у `useSchedule` при відкритті розкладу).

## 3. Потребує перевірки

1. **Жива авторизація через вікно Google OAuth (`google.accounts.oauth2.initTokenClient`) та реальна видача Google Classroom API**:
   - Логіку виклику OAuth, збереження токенів та обробки відповідей повністю перевірено за кодом (`frontend/components/ClassroomSyncButton.tsx`, `frontend/lib/useClassroomSubmissions.ts`, `backend/app/routers/classroom.py`).
   - Проте повноцінне проходження вікна входу Google у браузері вимагає реального студентського Google-акаунта домену коледжу та налаштованого `NEXT_PUBLIC_GOOGLE_CLIENT_ID` для поточного хоста.
2. **Системне вікно встановлення PWA (`beforeinstallprompt`) на реальних мобільних пристроях**:
   - Подія `beforeinstallprompt` спрацьовує лише у підтримуваних мобільних браузерах Chromium (наприклад, Chrome на Android) при дотриманні критеріїв PWA та HTTPS. На iPhone (Safari) ця подія браузером не підтримується за стандартом WebKit, тому застосунок (і інструкція) показує покрокову підказку через меню `"Поділитися"` → `"На початковий екран"`.
