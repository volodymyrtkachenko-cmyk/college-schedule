# Git Workflow Rules

- Після завершення реалізації змін або виправлень обов'язково автоматично робити `git add`, `git commit` з інформативним повідомленням та `git push` в репозиторій без окремого прохання користувача.
- Не комітити тимчасові файли огляду чи службові логи (наприклад, `code_review.txt`, `.DS_Store`).
