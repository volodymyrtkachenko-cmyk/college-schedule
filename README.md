# 🎓 Розклад занять ДФКР (Дніпровський фаховий коледж радіоелектроніки)

Сучасний прогресивний веб-застосунок (PWA) розкладу занять, моніторингу освітнього процесу та інтеграції з Google Classroom для студентів, викладачів та адміністрації Дніпровського фахового коледжу радіоелектроніки (**ДФКР / КРЕ**).

---

## 🚀 Основні можливості

- **Розклад для студентів і викладачів (День / Тиждень)**:
  - Перегляд на сьогодні та на тиждень (чисельник / знаменник), інтерактивний свайп-пейджер на смартфонах та тижнева сітка Пн–Пт на ПК зі швидкою навігацією стрілками клавіатури `←` / `→`.
  - Швидкий вибір групи або викладача зі збереженням останніх виборів та миттєвий перехід на розклад викладача прямо з картки пари.
  - Підтримка підгруп (`1 підгр.`, `2 підгр.`, `Обидві`) для двовикладацьких пар із роздільними кабінетами та онлайн-посиланнями.
  - Автоматичний індикатор формату навчання курсу (**Очно / Дистанційно**) з підтримкою дат-винятків.
  - Генерація стильної картинки розкладу дня чи тижня або текстове копіювання в один клік.

- **Жива пара та розклад дзвінків (`/bells`)**:
  - Автоматичне визначення поточної пари та перерви в реальному часі за часовим поясом `Europe/Kyiv` (`● ще N хв` та прогрес-лінія всередині картки).
  - Підтримка **скорочених днів (пари по 50 хв)** з автоматичним перерахунком часу дзвінків.

- **Онлайн-заняття та захист посилань**:
  - Автоматичне розпізнавання платформи відеозв'язку (`Google Meet`, `Zoom`, `Онлайн`) із підключенням в один клік.
  - Захист посилань від сторонніх гостей (`🔒 Meet` / `🔒 Zoom`): студенти відкривають посилання своєї групи після прив'язки Google Classroom, а викладачі — за допомогою PIN-коду викладача.

- **Інтеграція з Google Classroom, Завдання та Оцінки (GPA)**:
  - Фонова серверна та тиха клієнтська синхронізація домашніх завдань, дедлайнів, статусів здачі та оцінок.
  - Відображення активних незданих завдань прямо на картках відповідних пар у розкладі.
  - Окрема вкладка **«Завдання»** (збереження боргів з минулих тижнів, фільтри за предметом і статусом) та **«Оцінки»** (розрахунок середнього балу за 5-бальною та 12-бальною системами, розподіл оцінок `«5» / «4» / «3» / «2»` та автоматичне визначення реальної шкали оцінювання 5 / 12 / 100 б.).

- **Візуальний Гід (Stories), Аналітика та SEO**:
  - Лаконічні 15-секундні майстри першого входу для студента і викладача та інтерактивний Гід у форматі 6 Stories (`💡`).
  - Сторінка **«Статистика занять» (`/statistics`)** для контролю вичитаних годин та пар за семестр і **«Графік освітнього процесу» (`/educational-process`)**.
  - Індивідуальні SSR/ISR сторінки для всіх навчальних груп (`/group/[code]`), викладачів (`/teacher/[slug]`) та розкладу дзвінків (`/bells`) із розміткою Schema.org та динамічним `sitemap.xml`.

- **PWA та робота без інтернету (Offline)**:
  - Встановлення як нативний застосунок на телефон (iOS / Android) або ПК, миттєва віддача розкладу з локального кешу + `ETag` (`304 Not Modified`), 6 акцентних палітр та світла/темна теми (WCAG AA).

- **Панель адміністратора (`/admin`)**:
  - **Автоматичний та ручний імпорт з `kre.dp.ua`**: парсинг розкладу та замін із детекцією одноденних перестановок (`🔀 Перестановка`), збереженням несканованих тижнів і миттєвим відкатом публікації (Rollback).
  - **Генератор розкладу (Google OR-Tools CP-SAT)**: автоматичне складання розкладу з урахуванням навчальних планів, обмежень викладачів та симетрії тижнів.
  - **Візуальний редактор**: редагування постійного розкладу та разових замін, переміщення пар (Drag-and-Drop / клік), копіювання дня, керування довідниками, семестром, скороченими днями та ролями (`admin`, `editor`, `viewer`).

## 🛠 Технологічний стек

### Backend
- **Python 3.12** + **FastAPI**
- **SQLAlchemy 2.0 (Async)** + **Alembic** + **PostgreSQL** (`psycopg`)
- **Google OR-Tools (CP-SAT Solver)** для оптимізації розкладу
- **Selectolax (Lexbor)** + **HTTPX** для швидкого парсингу розкладу
- **PyJWT**, **pwdlib (Argon2)**, **Cryptography (Fernet)**, **SlowAPI** для безпеки та захисту токенів
- **Pytest** (308+ автоматизованих тестів)

### Frontend
- **Next.js 14 (App Router, SSR/ISR)** + **React 18** + **TypeScript (Strict)**
- **Tailwind CSS** (семантичні дизайн-токени, 6 кольорових акцентів, перевірка контрасту WCAG AA)
- **Framer Motion** + **View Transitions API**
- **@ducanh2912/next-pwa** (Service Worker, маніфест, офлайн-режим)

## 💻 Локальний запуск та розробка

### 1. Клонування репозиторію
```bash
git clone https://github.com/volodymyrtkachenko-cmyk/college-schedule.git
cd college-schedule
```

### 2. Налаштування Backend
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt

# Налаштуйте змінні оточення (створіть .env на основі .env.example)
# Запуск міграцій
(cd backend && alembic upgrade head)

# Запуск сервера
./.venv/bin/uvicorn app.main:app --reload --port 8000 --app-dir backend
```
API документація Swagger доступна за адресою: `http://localhost:8000/docs`.

### 3. Налаштування Frontend
```bash
cd frontend
npm install
npm run dev
```
Фронтенд буде доступний за адресою: `http://localhost:3000`.
