# 🎓 Розклад занять ДФКР (Дніпровський фаховий коледж радіоелектроніки)

Сучасна, швидка та надійна система управління та перегляду розкладу занять для студентів, викладачів та навчальної частини коледжу.

---

## 🚀 Основні можливості

- **Студентський та викладацький розклад**:
  - Перегляд на "Сьогодні" та "Тиждень" (чисельник / знаменник).
  - Швидкий пошук групи або викладача.
  - Повне відображення предметів, аудиторій, підгруп і замін без обрізання тексту.
  - Підтримка клікабельних посилань (Google Meet, Zoom, Classroom, Moodle) у примітках до занять.

- **PWA та робота Offline (Офлайн-режим)**:
  - Встановлення як додаток на телефон (iOS / Android) або комп'ютер.
  - Миттєве завантаження завдяки кешуванню `stale-while-revalidate`.
  - Можливість примусового збереження розкладу на пристрій для роботи без доступу до інтернету (наприклад, у бомбосховищі або метро).
  - Fallback-сторінка `~offline` при відсутності мережі.

- **Панель адміністратора та диспетчера**:
  - **Автоматичний імпортер**: парсинг та імпорт змін і розкладу з офіційного сайту коледжу (`kre.dp.ua`) з автоматичним збереженням несканованих тижнів.
  - **Генератор розкладу (OR-Tools CP-SAT)**: автоматичне складання розкладу з урахуванням обмежень викладачів, сумісності аудиторій та навантаження.
  - **Редагування розкладу Drag-and-Drop & Клік**: швидке переміщення пар, заміна кабінетів, оптимістичне підсвічування вільних слотів (зелене) та слотів із замінами (жовте).
  - **Scoped Publications та атомарний відкат (Rollback)**: фіксація змін у вигляді снапшотів публікацій з можливістю повернення до попередньої версії в один клік.
  - **Довідники**: факультети, відділення, групи, викладачі, предмети, аудиторії та розклад дзвінків.
  - **Розмежування прав доступу (RBAC)**: захищені ролі `admin`, `editor`, `viewer`.

## 🛠 Технологічний стек

### Backend
- **Python 3.12 / 3.14** + **FastAPI**
- **SQLAlchemy 2.0 (Async)** + **Alembic** (міграції бази даних)
- **PostgreSQL (Neon)** з підтримкою пулу з'єднань і транзакційних advisory locks
- **Google OR-Tools (CP-SAT Solver)** для вирішення задач оптимізації розкладу
- **Pydantic v2** для суворої валідації схем
- **Pytest** (понад 190 автоматизованих тестів)

### Frontend
- **Next.js 14 (App Router)** + **React 18** + **TypeScript**
- **Tailwind CSS** (темна тема, кастомні дизайн-токени `#0b1120`, семантичні стилі)
- **@ducanh2912/next-pwa** (Service Worker, маніфест, офлайн-сторінка)
- **Єдиний ToastProvider** для доступних та синхронізованих системних сповіщень

### Інфраструктура та Деплой
- **Fly.io**: хостинг бекенду в контейнері Docker.
- **Vercel**: швидкий глобальний CDN хостинг фронтенду Next.js.
- **GitHub Actions**: автоматизований CI/CD pipeline розгортання при пуші в `main`.

## 💻 Локальний запуск та розробка

### 1. Клонування репозиторію
```bash
git clone https://github.com/volodymyrtkachenko-cmyk/college-schedule.git
cd college-schedule
```

### 2. Налаштування Backend
```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Налаштуйте змінні оточення (створіть .env на основі .env.example)
# Приклад: DATABASE_URL=postgresql+asyncpg://user:pass@localhost:5432/schedule_db

# Запуск міграцій
alembic upgrade head

# Запуск сервера
uvicorn app.main:app --reload --port 8000
```
API документація Swagger доступна за адресою: `http://localhost:8000/docs`.

### 3. Налаштування Frontend
```bash
cd ../frontend
npm install

# Запуск сервера розробки
npm run dev -- -p 3000
```
Фронтенд буде доступний за адресою: `http://localhost:3000`.

## 📦 Резервне копіювання бази даних (T31)

У проєкті реалізовано інструмент для швидкого створення стисненого дампу бази даних:
```bash
# У середовищі Docker або на Fly.io:
python3 scripts/db_backup.py --dir /data/backups
```
Скрипт перевіряє наявність `pg_dump`, вивантажує повний дамп схеми та даних з параметрами безпеки `--clean --if-exists --no-owner` і стискає результат через `gzip`.
